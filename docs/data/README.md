# Kiribati TB — Data pipeline

## Overview

All inputs are derived from three primary sources:

| Domain                               | Source                                                 | Processing                     |
| ------------------------------------ | ------------------------------------------------------ | ------------------------------ |
| TB surveillance and burden estimates | WHO Global TB Report 2026                              | Julia                          |
| Demography                           | UN World Population Prospects 2024, via `wpp2024`      | R extraction, Julia processing |
| Age-specific contacts                | Prem et al. (2021), Solomon Islands, via `contactdata` | R extraction, Julia processing |

The workflow separates **raw data**, **processed data**, **exploratory analysis** and **scientific modelling**.

Processed inputs are reproducible from the raw sources. Model-specific parameterisation, observation likelihoods and epidemiological assumptions are handled separately.

## 1. Reproducing the data

Run commands from the repository root.

### Extract external sources

In R:

```r
source("scripts/data/extract_wpp2024.R")
source("scripts/data/extract_prem.R")
```

WHO exports are placed manually under `data/raw/who/2026/`, retaining their original contents. Original filenames, download dates and source versions should be recorded in `sources.md`.

### Build processed data

In Julia:

```julia
include("scripts/data/build_surveillance.jl")
include("scripts/data/build_estimates.jl")
include("scripts/data/build_demography.jl")
include("scripts/data/build_contacts.jl")
include("scripts/data/build_reciprocal_contacts.jl")
```

### Validate

```julia
include("scripts/data/validate_demography.jl")
```

Surveillance processing also generates consistency reports under `data/processed/surveillance/validation/`.

Contact processing compares the reconstructed matrix with the legacy input and verifies age-band contact conservation. The reciprocity script checks the corrected matrices across selected population years.

### Explore

```julia
include("scripts/data/explore_surveillance.jl")
include("scripts/data/explore_demography.jl")
include("scripts/data/decompose_notifications.jl")
```

Results are written to `results/data_exploration/`.

## 2. Demographic conventions

- Source: WPP2024 R package, Kiribati (country code 296).
- Population: single-year ages, both sexes and sex-specific counts.
- Time coverage: 1950–2100.
- Population: end-of-year values; midpoint denominators approximate annual person-time.
- Fertility: age-specific rates reconstructed from total fertility and its age distribution.
- Mortality: central death rates, not annual death probabilities.
- Migration: annual net migration.
- Processed population counts are expressed in persons, rather than thousands.

The reconstructed population, fertility, mortality and migration inputs reproduce the previous numerical inputs to floating-point precision.

## 3. Surveillance conventions

- Source: WHO Global TB Report 2026.
- Country: Kiribati.
- Reported surveillance observations are kept separate from WHO-generated estimates.
- Missing observations are not replaced with zeros.
- Reporting categories and treatment-cohort definitions are preserved.
- Historical smear-positive and smear-negative classifications are distinguished from modern pulmonary diagnostic categories.
- The 2024 combined childhood notification category is not artificially divided between ages 0–4 and 5–14.

Known inconsistencies are documented in `validation.md`.

## 4. Contact conventions

- Source: Prem et al. (2021), Solomon Islands.
- Original matrix: 16 age groups.
- Model-compatible matrix: 96 ages, 0–95.
- Rows represent contact recipients; columns represent contact sources, following the existing package convention.
- Contacts are allocated equally across source ages within each original band.
- The original matrix is not population-weighted or reciprocity-corrected.
- An optional correction enforces reciprocity using Kiribati age-group populations.
- Fixed-2023 and time-varying corrections are available.
- Any overall normalisation used in transmission dynamics belongs to the model layer.

## 5. Scientific limitations

WHO incidence and case-detection estimates are not independent of reported notification data.

Observed pulmonary/extrapulmonary notification proportions need not equal underlying disease-onset proportions.

The contact matrix is a synthetic Solomon Islands estimate, not a direct measurement of mixing in Kiribati.

Population-adjusted reciprocity changes the assumed contact structure and should be evaluated as a modelling choice.

## 6. Reproducibility policy

- Raw files are immutable.
- Processed files are generated by scripts, never edited manually.
- Exploration reads processed files without modifying them.
- Source versions and assumptions are documented.
- Known data inconsistencies are preserved and reported.
- Changes to processing logic require corresponding validation updates.

See `sources.md`, `definitions.md`, `validation.md` and `exploration.md` for further details.
